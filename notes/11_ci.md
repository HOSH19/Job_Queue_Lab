# Continuous Integration

CI runs the same checks on every pull request so "works on my machine" does not merge broken code.

Workflow: [`.github/workflows/ci.yml`](../.github/workflows/ci.yml)

## Jobs

1. **backend** — install Python deps → `ruff check` → `pytest`
2. **frontend** — `npm ci` → `oxlint` → `vitest` → `npm run build`

## Local equivalents

```bash
make lint
make test
```

## Pre-commit (optional)

[`.pre-commit-config.yaml`](../.pre-commit-config.yaml) runs `ruff` and `oxlint` before each commit:

```bash
pip install pre-commit
pre-commit install
```

Practice: treat a red CI check as a merge blocker, not a suggestion.
